The space has multiple dimensions with larger values of $P(x)$ in some areas
and smaller values in others.
\vskip 3ex
The question is this. How do we move $x$ to a point where $P(x)$ is higher.
\vskip 3ex
We need to calculate the gradient.
\vskip 3ex

The gradient of a scalar function that takes as input, x , which is multi-dimensional and returns a scalar is a vector of partial derivatives of the scalar in each dimension.

\vskip 3ex
The gradient represents the direction where value of $P(x)$ is higher.
\vskip 3ex
If we access the gradient of $P(x)$ we can move from $x$ to a region where $P(x)$'s value higher.

\subsection{Problem with gradient of probabilities}

Probabilities are normalized. They sum to one

\vskip 3ex
$\textbf{Property of probabilities } \mathcal{Z} = \int \mathcal{P}_{data} x dx = 1$
\vskip 3ex
Therefore
\vskip 3ex
\scalebox{1.5}{%
$\mathcal{P}_{data} = \left( \frac{f(x)}{\underbrace{\mathcal{Z}}_{\text{intractable}}}\right )$
}
\vskip 3ex
It is intractable because we cannot sum across multiple dimensions.Moreover the PDF can encounter numerical stabiliity issues in some regions where the probabiliities are very small.

\vskip 3ex
\subsection{Gradient of log of probabilities}
\begin{enumerate}
\item{${\nabla}_x \log \mathcal{P}_{data} (x) = {\nabla}_x \log f(x) {\nabla}_x \log ( \mathcal(Z) )$}
\item{Points in the same directiion as gradient of $\mathcal{P} (i.e) \nabla log(P) = \frac{\nabla p}{p}$ which mean we are dividing the vector by the scalar along all dimensions}
\item{More numerically stable because when $\nabla P$ is very small,
there are chances that 'p' is also very small.So according to the point
above if we take the ratio by dividing, it is not as small.}
\end{enumerate}

\section{Score of a Gaussian Distribution ( example in 1D )}

$\Large \textbf{ For } x \sim \mathcal{N}( \mu, {\sigma}^2 )$

So the probability distribution function is $p(x) = \frac{1}{2 \pi \sigma^2} \text{ exp } - \left( \frac{(x - \mu)^2}{2 \sigma^2})$

Therefore, score is $ s(x) = - \left( \frac{x - \mu}{\sigma^2} \right)$

\vskip 3ex
Now we know that finding the score of a Gaussian distribution is easy. So we take one point and add noise to it and scale it by $\sigma$

$ \tilde{x} = x + \sigma \epsilon, \epsilon = \mathcal{N}( \mu, \mathcal{I} )$

\vskip 3ex
\subsection{Perturbation kernel}

Not much is explained by the instructor. This is a facility to add noise.
$\Large q_{\sigma}(\tilde{x}) = \int \underbrace{q_{\sigma}(\tilde{x} \mid x) \mathcal{P}_{data}(x) dx}_{\substack {\text{Joint probability}} \\ q(\tilde{x} \mid x)}$

This is an expression that is also considered a Joint probability because if we integrate over $\tilde{x}$ and x, we get 1.

\section{ Wiener Process}

$\textbf{Idea }$: Continuous equivalent of adding increments of Gaussian noise

$\textbf{ Wiener Process }$ : Stochastic process with the following properties.

\begin{enumerate}
\item{$ W_0 = 0$ }
\item{$ W_T - W_s \sim \mathcal{N}(0, ( t-s ) \mathrm{I})$}
\item{ Only Increments are independent. Not the value of $W_t$ }
\end{enumerate}

Now we can derive the continuous formulation of DDPM and NCSN. Here we
show only the derivation of DDPM.

\scalebox{1.5}{
$x_t = \sqrt { 1 - \underbrace{\beta_T}_\text{Noise schedule} } x_{t-1} + \beta_t \epsilon$
}
\scalebox{1.5}{
$\underbrace{x_t = x_{t-1}}_\substack{\text{Differential evolution if x}  \\ \text{ as a function of } \\ \text{everything else}}$
}

$x_t - x_{t-1}$ is very small. So it is considered continuous.
$x_t - x_{t-1} = \left[\sqrt { 1 - \beta_t} - 1\right]  x_{t-1}+ \sqrt{\beta_t} \epsilon $ Why is 1 subtracted ?

$\beta_t = \beta(t) dt \text{ is rate at time t }$
 $x_t - x_{t-1} = \left[\sqrt { \cancel{1} - \beta(t) dt} - \cancel{1}\right]  x_{t-1}+ \sqrt{\beta(t) dt} \epsilon $ Why is 1 subtracted ?

When $dt$ tends to 0 we have taylor expansion which is $\frac{1}{2}$ of thet quantity.

\begin{tcolorbox}[fontupper=\Large,sharp corners, colback=teal!20, colframe=Aquamarine!10!blue]
  $dw = \sqrt {dt} \epsilon \text{ according to Wiener process }$
\end{tcolorbox}
 $\overbrace{dx}^\text{Differential evolution} \sim  \left[ 1 -    \frac{1}{2}\beta(t) dt -1\right]  x+ \sqrt{\beta(t) } dw $
\vskip 3ex
\scalebox{1.5}{
$dx = - \frac{1}{2}\beta(x) dt+ \sqrt{\beta(t) } dw$
}
In other words the noising forward process brings x closer to 0 but also adds noise so that the variance converges to 1.
DDPM is exactly the same process. We take a clean image and add noise in increments and after time steps 't', it converges to a normal distribution with mean 0 and variance 1.
